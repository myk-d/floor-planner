# Ідеї для розвитку — бeклог фіч

Список можливих доробок планувальника, згрупований за напрямами. Не план і не
зобов'язання — довідник, з якого обираємо наступні кроки.

**Контекст: особисте використання.** Ми з дружиною плануємо власну квартиру —
обмір → перепланування → оздоблення → інженерка → розстановка меблів → 3D, щоб
побачити результат і порахувати бюджет ремонту. Не комерційний продукт: немає клієнтів,
ролей, бренду, здачі документації замовнику. Тому весь «студійний» блок (узгодження з
клієнтом, ріелторський маркетинг, реєстри креслень, керування закупівлями підрядника,
BIM-обмін) — або пропускаємо, або беремо в мінімальній «для себе» версії. Позначки нижче.

**Обсяг зусиль:** ⚡ мала (години–день) · 🔧 середня (кілька днів) · 🏗️ велика (тиждень+)

**Актуальність для нас:** 🏠 прямо в ціль · 💤 надлишок для особистого використання (лише якщо цікаво)

**Статус:** ✅ вже є (частково) · ⛔ поза узгодженим обсягом

**Поза обсягом назавжди** (домовлено): багатоповерховість / кілька аркушів-поверхів;
конструктив (колони, балки, сходи, балкони, тераси, отвори в підлозі); дах; рельєф.
**Відкладено:** калька-підкладка під обведення (потрібен Firebase Storage або base64 в документі).

## Частина A. Основний список

### 1. Малювання та редагування

- ⚡ Введення довжини стіни з клавіатури під час малювання
- ⚡ Живий показ довжини / кута сегмента поки тягнеш
- ⚡ Прив'язка «по продовженню» / перпендикуляр / вирівнювання з іншими вузлами (snap tracking)
- ⚡ Прив'язка до середини стіни; налаштування кроку кута (15/30/45°)
- ⚡ «Формат по зразку» — копіювати матеріал/колір зі стіни/кімнати/меблів
- ⚡ Групування об'єктів (group / ungroup); блокування окремого об'єкта, не лише шару
- ⚡ Напрямні лінії, які витягуєш з лінійки, з числовою позицією
- 🔧 Дугові (криволінійні) стіни
- 🔧 Еркер як пресет (кут + виступ)
- 🔧 Багатошарова стіна (несуча + утеплювач + оздоблення) з різною штриховкою шарів
- 🔧 Скруглення / фаска кута стін (fillet / chamfer)
- 🔧 Масив / дублювання по лінії чи колу (array)
- 🔧 Розділити / об'єднати кімнати; конвертувати поверхню ↔ кімната
- 🔧 Редагування полігону кімнати (додати/прибрати вузол)
- 🔧 Прив'язка меблів до стіни + автоповорот до неї
- 🔧 Підсвітка колізій (меблі налазять одні на одних / на стіну)
- 🔧 Калібрування масштабу: намалювати відомий відрізок → задати довжину → перерахувати всю сцену
- 🔧 Дзеркалити / обертати весь план; задати базову точку (0,0)
- 🔧 Панель історії дій зі списком і переходом до будь-якого кроку
- ⚡ Показ координат курсора (X, Y)

### 2. Отвори (двері / вікна / прорізи)

- ⚡ Типи дверей: розпашні, розсувні, книжка, подвійні, «французькі», в касеті (pocket)
- ⚡ Напрямок і кут відчинення (4 варіанти + кут дуги)
- ⚡ Типи вікон: стулкове, розсувне, глухе, аркове; пресети висоти підвіконня
- 🔧 Ніші / заглиблення в стіні (отвір неповної глибини)
- 🔧 Роздавальне вікно (кухня-вітальня), поріг/сходинка біля дверей
- 🔧 Таблиця вікон і дверей (schedule) з розмірами, к-стю, підписами

### 3. Розміри та анотації

- ⚡ Позначки рівня підлоги (±0.000, перепади)
- ⚡ Автонумерація приміщень + експлікація з номерами
- ⚡ Позначки розгорток на плані (звідки й куди дивимось)
- 🔧 Розмір радіуса / діаметра / кута
- 🔧 Виноски з текстом (leader), окремий шар приміток
- 🔧 Стилі розмірних ліній (стрілки / засічки / крапки), налаштування виносу
- 🔧 Кнопка «проставити всі розміри» одним кліком

### 4. Приміщення та оздоблення

- 🔧 Висота стелі **окремо для кожної кімнати** (зараз одна глобальна `wallHeight`) ✅ частково
- 🔧 Оздоблення стін по кімнатах (шпалери/фарба/плитка) з площею **за вирахуванням отворів**
- 🔧 Акцентна стіна — колір/матеріал на одну стіну кімнати
- 🔧 Стельове покриття по кімнатах (фарба / натяжна / гіпсокартон) + площа
- 🔧 Підвісна/багаторівнева стеля як зона зі своєю висотою
- ⚡ Плінтус / стельовий карниз — периметр кімнати × погонний метраж
- 🔧 Пресети типу кімнати (кухня/санвузол/спальня) що задають дефолти оздоблення
- 🔧 «Пиріг» підлоги: стяжка + утеплювач + покриття → сумарна висота, підрізка дверей
- 🔧 Пороги/переходи між покриттями; ухили підлоги в санвузлі
- 🏗️ Розкладка плитки: розмір плитки, шов, підрахунок штук, схема укладання

### 5. Меблі та каталог

- ⚡ Обране / нещодавні; пошук за габаритом
- ⚡ Ціна на позицію → кошторис розстановки; множник кількості (6× стілець)
- ⚡ Дзеркалити меблі; прив'язка повороту 15°
- 🔧 Власні меблі: намалювати прямокутник/полігон → зберегти в каталог
- 🔧 Настінні меблі (ТВ, полиці, шафки) з висотою підвісу
- 🔧 Реалістичніший 2D-силует зверху замість прямокутника
- 🔧 Набори меблів (спальний комплект) одним перетягуванням
- 🔧 Зони габариту/проходу (розчин дверей, прохід 60 см) з попередженнями
- 🔧 Ергономіка: робочий трикутник кухні, висув стільця, радіус розвороту
- 🏗️ Параметричні модулі (кухня із секцій, шафа з N дверей) + погонні метри
- ⛔ Завантаження власних 3D-моделей/іконок — потребує Storage

### 6. Інженерні мережі

- 🔧 Автовисоти символів (розетка 30, вимикач 90 см) + підпис висоти на плані ✅ частково
- 🔧 Перевірка правил (розетка не над плитою, вимикач біля дверей тощо)
- 🔧 Специфікація по розділах: к-сть розеток/світла, метраж кабелю за перерізами, довжина труб ✅ групування є
- 🔧 Зв'язок «вимикач → світильник», прохідні/перехресні схеми
- 🏗️ Однолінійна схема щитка + розрахунок навантаження групи (потужність → автомат)
- 🔧 Сантехніка: діаметри й ухили каналізації, гребінка/колектор води, крани, лічильник, фільтр
- 🔧 Опалення: підбір радіатора за площею / тепловтратами кімнати; крани на радіаторах
- 🏗️ Тепла підлога: розкладка змійка/равлик з кроком, довжина контуру, вихід на колектор
- 🔧 Слаботочка окремим підрозділом (інтернет, ТВ, домофон, CCTV з конусами огляду, сигналізація, розумний дім)
- 🔧 Освітлення: орієнтовний розрахунок освітленості (люкс), світлові сцени
- 🏗️ Вентиляція: канали, дифузори, витяжки, рекуператор
- 🔧 Легенда/специфікація кожного розділу окремим аркушем

### 7. Ремонт і кошторис

- 🔧 Відомість демонтажу (площі стін/підлог до знесення, к-сть отворів)
- 🔧 Відомість робіт з автоплощами (штукатурка X м², стяжка Y м², шпалери Z м²)
- 🏗️ Кошторис матеріалів за нормами витрати + ціни, експорт у CSV/таблицю
- 🔧 Норми витрати матеріалів (кг/м², покриття) — редагована таблиця; коеф. відходів
- 🔧 Вартість робіт (розцінки за одиницю) + підсумок
- 🔧 Режим порівняння «до / після» — два плани поруч
- ⚡ Етапи ремонту / чек-лист у проєкті
- 🔧 Бюджет vs факт — облік витрат

### 8. 3D

- 🔧 Збережені ракурси камер у сцені + кнопка «стати на камеру»
- 🔧 Автоприховування стін, що ближче до камери
- ⚡ Перемикач стелі on/off; вид «ляльковий будиночок» (згори без стелі)
- 🔧 Режим прогулянки від першої особи (WASD + миша)
- 🔧 Сонце за компасом + час доби, м'які тіні; температура світла ламп (2700–6500 K)
- 🔧 Рендер 3D-скріншота у високій якості з експортом; облітання (turntable) відео
- 🔧 Вимірювання в 3D; розріз січною площиною
- 🔧 Фарбування матеріалів прямо в 3D (клік на стіну → застосувати оздоблення)
- 🏗️ Вікна/двері як 3D-об'єкти (рама, скло) замість прорізу
- 🏗️ Меблі як glTF-моделі замість боксів; перетягування меблів у 3D
- 🏗️ PBR-матеріали (roughness / metalness / normal); запечена AO

### 9. Експорт і документація

- ⚡ Редаговані поля штампа (замовник, адреса, дата, № аркуша); логотип/водяний знак
- ⚡ Експорт кожної кімнати окремим PNG; прозоре тло
- 🔧 Друк у точному масштабі з калібрувальною лінійкою; постерний друк A4-плитками
- 🔧 Пакетний експорт усіх розгорток
- 🔧 Комплект аркушів однієї квартири в один PDF (план + розгортки + електрика + сантехніка +
  підлоги + стелі + меблі) — ⚠️ уточнити межу з виключеними «аркушами»
- 🏗️ Експорт **DXF/DWG** для інженерів/дизайнерів
- 🔧 Експорт таблиць (кімнати, меблі, кошторис) у CSV / Google Sheets
- 🔧 PDF із перемиканими шарами (в Acrobat)

### 10. Проєкти та спільна робота

- ⚡ Папки / теги для проєктів, кошик; авто-обкладинка проєкту (скрін плану)
- ⚡ Дублювати проєкт із меблями / без
- 🔧 Версії проєкту: снапшоти + відкат; журнал змін
- 🔧 Realtime-редагування вдвох (Firestore listeners) + індикатор присутності ✅ автозбереження є
- 🔧 Коментарі-пінки на плані
- 🔧 Шаблони проєктів (типові планування — «студія», «однокімнатна»)
- 🔧 Порівняння двох проєктів поряд

### 11. UX / якість

- ⚡ Довідка гарячих клавіш (клавіша `?`); підказки зі скороченнями
- ⚡ Клавіша `F` — центрувати на вибраному; ізоляція виду (сховати все, крім вибраного)
- ⚡ Числові поля властивостей зі стрілками ± і одиницями; пан пробілом
- ⚡ Пресети сітки (10/25/50/100 см); поповер з усіма типами прив'язок
- 🔧 Командна палітра (Ctrl+K)
- 🔧 Міні-мапа / навігатор у кутку
- 🔧 Офлайн-режим і чернетка в IndexedDB; розв'язання конфлікту автозбереження
- 🔧 Темна тема інтерфейсу
- 🔧 Локалізація (зараз лише українська) — каркас для EN та ін.
- 🔧 Доступність (навігація клавіатурою, ARIA, контраст)
- 🏗️ Тач-версія для планшета
- 🔧 Віртуалізація рендера для дуже великих сцен

## Частина B. Додатковий список (розширення)

### 12. Аналіз і валідація плану

- 🔧 Перевірка норм ДБН: мінімальна ширина коридору, площа кімнати, висота стелі
- 🔧 Коефіцієнт природного освітлення (площа вікон / площа підлоги) по кімнатах
- 🔧 Безбар'єрність: ширина проходів, радіуси розворотів для візка, ширина дверей
- 🔧 Шляхи руху / евакуації — трасування й довжина
- 🔧 Співвідношення площ: житлова / загальна / корисна / коефіцієнт компактності
- 🔧 Інсоляція: скільки годин прямого сонця отримує кімната (за компасом і широтою)
- 🔧 Перевірка «мокрі зони» — санвузол/кухня повинні мати гідроізоляцію (авто-підказка зони)
- ⚡ Індикатор «незамкнений контур» / «кімната без імені» / «двері без стіни»

### 13. Допомога з плануванням і розстановкою

- 🏗️ Автопланування: розкидати меблі за типом кімнати (евристики / AI)
- 🔧 Пропозиції розстановки з поясненням (чому так)
- 🔧 Перевірка «пройде диван у двері / у ліфт / на сходах»
- 🔧 Зонування відкритого простору (кухня-вітальня — де межа зон)
- 🔧 Генерація варіантів перегородок під задану кількість кімнат

### 14. Варіанти планування (в одному проєкті)

- 🔧 Кілька варіантів розстановки/перегородок, швидке перемикання
- 🔧 Дублювати поточну сцену як новий варіант
- 🔧 Порівняння варіантів: площі, кошторис, к-сть меблів — таблицею
- ⚡ Позначити варіант як «основний»

### 15. Обмір на місці

- 🔧 Режим введення кімнати за розмірами стін (ввів 4+ стіни з довжинами → кімната)
- 🔧 Імпорт обмірів із лазерного далекоміра (CSV / ручне введення списком)
- 🔧 Режим «уточнення»: клікнув стіну, вписав фактичну довжину — план підганяється
- ⛔ Фото, прив'язані до стін/кімнат (потрібен Storage)
- ⚡ Голосове / швидке введення розмірів (кома-роздільник: `3.2, 2.8, 3.2, 2.8`)

### 16. Презентація для клієнта

- ⚡ Повноекранний режим перегляду без панелей
- 🔧 Слайдшоу: план → 3D-ракурси → розгортки, з автопрокруткою
- 🔧 Брендована обкладинка PDF (лого, контакти, опис проєкту)
- 🔧 A/B-порівняння варіантів планування для клієнта
- 🔧 Режим «тільки коментування» для клієнта (пінки, без редагування)

### 17. Дані та інтеграції

- 🔧 Імпорт із інших форматів: `.dxf`, `.svg`, `floorplanner`/`remplanner` експорт
- 🔧 Google Sheets — синхронізація кошторису й специфікацій
- 🔧 Список покупок меблів (з каталожних позицій) з посиланнями/цінами
- 🔧 QR на кресленні → відкриває 3D-тур / актуальну версію
- ⚡ Telegram/email-сповіщення про зміни в спільному проєкті
- 🏗️ Публічне read-only посилання на 3D-тур (⚠️ приватність — окремий токен, не обліковка)

### 18. Стіни та планування — глибше

- 🔧 Автоматичне оздоблення внутрішнього контуру (лінія чистових стін всередині чорнових)
- 🔧 Кути стін: чисте з'єднання під довільним кутом (зараз кругла заглушка) ✅ частково
- 🔧 Перегородки різної товщини з бібліотеки (ГКЛ 75/100/125, цегла 120, блок 100…)
- 🔧 Звукоізоляційний клас перегородки (довідково)
- 🔧 Вентканали / короби як спец-об'єкт (не конструктив — інженерна шахта)
- 🔧 Стояки (водопровід/каналізація/опалення) як фіксовані точки з прив'язкою труб ✅ символ є

### 19. Робота з кресленням

- ⚡ Порядок шарів (z-order) вручну для перекриттів
- ⚡ Заморозити шар (видно, але не клікається) — окремо від «сховати» і «заблокувати»
- 🔧 Фільтр видимості за статусом (показати лише «нове» / лише «демонтаж»)
- 🔧 Кольорові теми креслення користувача (свої палітри поверх line/blueprint/color)
- 🔧 Друкована легенда матеріалів і умовних позначень (авто зі сцени)
- ⚡ Товщина ліній / масштаб тексту як глобальний множник для експорту

### 20. Технічне / платформа

- 🔧 PWA: встановлення застосунку, офлайн-кеш
- 🔧 Автобекап усіх проєктів у `.floorplan` (експорт архіву)
- 🔧 Кошик видалених проєктів із відновленням (30 днів)
- 🔧 Телеметрія помилок (Sentry) + кнопка «повідомити про проблему»
- 🔧 E2E-тести ключових сценаріїв (Playwright)
- ⚡ Індикатор «незбережено» + попередження при виході ✅ є частково
- 🔧 Ліміт розміру документа Firestore (1 МБ) — стиснення сцени / винесення важкого

## Частина C. Ще ідеї — нішеві та професійні

### 21. Спеціалізовані простори

- 🔧 **Гардероб-конструктор**: внутрішнє наповнення шафи (штанги, полиці, шухляди, взуттєвниці) + розкрій
- 🔧 **Кухня**: погонні метри низу/верху, площа фартуха, вирізи під мийку/варильну, кутові рішення, зазори перед технікою
- 🔧 **Санвузол**: зони обслуговування сантехніки (унітаз 20 см з боків / 60 см спереду), позиція трапа, рушникосушка, дзеркало+світло
- 🔧 **Спальня**: зазор з боків ліжка, розчин дверцят шафи
- 🔧 Правила-підказки для кожного типу приміщення (з чеклистом)

### 22. Світлодизайн (поглиблено)

- 🔧 Шари світла: загальне / робоче / акцентне / декоративне — окремими групами
- 🔧 Теплова карта освітленості (люкс) накладенням на 2D-план
- 🔧 Світлові сцени (вечір / прибирання / прийом гостей) + прив'язка до груп
- 🔧 Розкладка світильників за сіткою з рекомендованим кроком
- 🔧 Розумне світло: DALI/Zigbee-групи, димери, датчики руху як окремий шар

### 23. Комплект робочої документації (окремі аркуші)

- 🔧 **План стелі** (RCP) — світильники, карнизи, перепади рівнів, вентиляція, вид згори
- 🔧 **План розстановки меблів** (FF&E) з нумерацією й специфікацією
- 🔧 **План розеток і слаботочки**; **план освітлення**; **план сантехніки** — окремо
- 🔧 **Матриця оздоблення** (кімнати × поверхні: підлога / стіни / стеля / плінтус)
- 🔧 **Паспорт кімнати** — одна сторінка: розміри, площа, оздоблення, обладнання
- 🔧 **План демонтажу** окремим аркушем
- 🔧 **План прив'язок** (setting-out) — розміри від базової точки / координатної сітки
- 🔧 **Розгортки санвузлів з розкладкою плитки** (сітка плитки на розгортці стіни)
- 🔧 **Відомість дверей і вікон з їх фасадами**
- ⚡ **Реєстр креслень** + історія редакцій (revisions)
- 🔧 Аркуш приміток і специфікацій (текстовий)

### 24. Перепланування та узгодження

- 🔧 Документ «до / після» з автопідсвіткою змін (які стіни зникли/додались, отвори)
- 🔧 Позначка «несуча стіна» → блокує демонтаж, показує попередження
- 🔧 Генерація тексту технічного опису перепланування
- 🔧 Експлікація до та після з дельтою площ

### 25. Клімат та енергоефективність

- 🔧 Тепловтрати всієї квартири й по кімнатах (U-значення огороджень, кліматична зона)
- 🔧 Орієнтовний клас енергоефективності
- 🔧 Підказки містків холоду (кути, примикання балкона ⛔ балкон поза обсягом — лише стіна)
- 🔧 Коеф. заскління (площа вікон / площа підлоги) — норма інсоляції
- 🔧 Зони ризику конденсату / плісняви (кути зовнішніх стін, санвузол)

### 26. Пожежна безпека та безпека

- ⚡ Димові / чадні датчики, вогнегасник, протипожежні двері як символи
- 🔧 Довжина шляху евакуації до виходу
- ⚡ Поручні / опори в санвузлі (безбар'єрність)

### 27. Закупівлі та ведення проєкту

- 🔧 Список покупок: позиції, кількість, ціна, посилання, термін постачання
- 🔧 Порівняння комерційних пропозицій від кількох постачальників
- 🔧 Календар постачань, прив'язаний до етапів робіт
- 🔧 Дефектна відомість (punch list) з прив'язкою до місця на плані
- 🔧 Журнал робіт / щоденник; контакти підрядників
- 🔧 Дашборд бюджету: план / факт / залишок / непередбачені
- ⛔ Фото прогресу по кімнатах і датах (потрібен Storage)

### 28. Клієнтські узгодження

- 🔧 Трекер вибору (клієнт обирає: плитка A чи B, колір стіни, модель змішувача)
- 🔧 Погодження по кімнатах — клієнт «підписує» кожне рішення
- 🔧 Дошка натхнення / референсів (⛔ зображення — Storage)
- 🔧 Статуси коментарів (відкрито / вирішено)

### 29. Нерухомість і маркетинг

- 🔧 Генерація «ріелторського» плану — чистий, брендований, з площею й «створено в…»
- 🔧 Бейдж загальної площі та кількості кімнат
- 🔧 Віртуальне вмеблювання порожнього плану (staging) для оголошення
- ⚡ Експорт плану без розмірів/інженерки — «для покупця»

### 30. AI та автоматизація — 💤 не робимо

Домовлено: жодних LLM / генеративних функцій. Лишаємо розділ як архів ідей.

- 💤 🏗️ Редагування природною мовою («додай вікно на північній стіні», «зроби кухню 12 м²»)
- 💤 🏗️ Асистент у застосунку (чат) з доступом до сцени
- 💤 🏗️ Генерація плану з фото / ескізу
- 💤 🔧 Підказки покращень планування

*Примітка:* «авто-простановка розмірів» і «визначення типу кімнати за меблями» — це звичайні
алгоритми/евристики, не AI. Вони лишаються в розд. 3 (кнопка «проставити всі розміри») і
розд. 12 (індикатори помилок) і не підпадають під це обмеження.

### 31. Шаблони та бібліотеки

- 🔧 Типові планування українських серій (хрущовка, чешка, сталінка, типова новобудова)
- ⚡ Шаблони кімнат (стандартний санвузол, стандартна кухня-ніша)
- 🔧 Бібліотека вузлів/деталей (типові примикання стін, пороги, укоси)
- ⚡ Користувацькі шаблони проєкту з поточного

### 32. Одиниці та регіональні стандарти

- 🔧 Імперські одиниці (фути / дюйми) перемикачем
- 🔧 Регіональні пресети (висоти розеток/вимикачів, розміри дверей, норми)
- ⚡ Формати паперу ANSI (Letter / Tabloid) додатково до ISO A

### 33. Розширене редагування

- ⚡ Вибір за критерієм: усі цегляні стіни / усі об'єкти шару / усі однакові меблі
- ⚡ Знайти й замінити матеріал по всій сцені; масове редагування властивостей
- ⚡ Числове переміщення (dX, dY) і поворот на точний кут вибраного
- 🔧 Масив уздовж довільної траєкторії
- ⚡ Показ відстані до найближчої стіни під час перетягування меблів
- ⚡ Індикатори рівних проміжків (smart spacing) при вирівнюванні

### 34. Візуальні стилі креслення

- ⚡ Poché — суцільно-чорні стіни (архітектурний стиль) перемикачем
- ⚡ Варіанти «синьки»: блакитна / сепія / темна
- ⚡ Чорно-білий (grayscale) експорт
- 🔧 Користувацькі стилі ліній і додаткові штриховки матеріалів

### 35. Рівні підлоги в межах квартири

- 🔧 Подіум / піднята зона / сходинка як поверхня з висотою (не «отвір у підлозі»)
- ⚡ Позначка безпорогових дверей; пандус для безбар'єрності

### 36. Столярні розгортки

- 🔧 Розгортка окремого предмета (шафа, кухня, стелаж) з розмірами й секціями — як розгортка
  стіни, але для меблів (millwork elevation)
- 🔧 Автопідпис матеріалів фасадів і фурнітури

### 37. Циркуляція та логістика

- 🔧 Діаграма проходів: підсвітити коридори вужчі за 90 см, тупики
- 🔧 Перевірка «чи пройде холодильник/диван від входу до місця» по ширині проходів
- ⚡ Правило «меблі перед радіатором / конвектором» — попередження

### 38. Вікна: аксесуари

- 🔧 Штори / жалюзі / рулонні / карнизи як об'єкти з довжиною карниза
- ⚡ Заміри отворів для замовлення (ширина × висота × к-сть) окремою таблицею

### 39. Спільна робота (глибше)

- 🔧 Курсори учасників у реальному часі; режим «слідувати» за іншим
- ⚡ @згадки в коментарях; стрічка сповіщень про зміни
- 🏗️ Аудіо-huddle усередині проєкту

### 40. Навігація та види

- ⚡ Закладки видів (збережені зум/пан 2D)
- 🔧 Розділений екран: 2D і 3D поруч
- 🔧 Вертикальний розріз квартири (січна площина в 2D)
- 🔧 Аксонометрія / ізометрія 2D-плану
- ⚡ Пресети шарів («показати лише електрику», «лише оздоблення»)

## Орієнтовний порядок — під наш сценарій (обмір → ремонт → меблі)

**Хвиля 1 — точно перенести свою квартиру в план:**
1. Введення довжини стіни з клавіатури + живі розміри під час малювання
2. Режим обміру: ввів довжини стін по колу → кімната; режим «уточнення» (клік по стіні → фактична довжина)
3. Калібрування масштабу; діагональна перевірка кімнати (реальні стіни не прямокутні)
4. Висота стелі окремо по кімнатах
5. Довідка гарячих клавіш, `F` — центрувати на вибраному

**Хвиля 2 — перепланування:**
6. Позначка «несуча стіна» → блокує демонтаж + попередження
7. Варіанти планування в одному проєкті (порівняти 2–3 розкладки перегородок удвох)
8. Документ «до / після» з підсвіткою змін (+ авто-текст техопису, якщо узгоджувати)
9. Типи дверей/вікон і напрямок відчинення

**Хвиля 3 — оздоблення й бюджет:**
10. Оздоблення стін / стелі / підлоги по кімнатах з площами (мінус отвори)
11. Кошторис матеріалів за нормами витрати + ціни + підсумок (скільки коштує ремонт)
12. Розкладка плитки (скільки плитки купити, схема укладання)
13. Плінтус / карниз — погонні метри; «пиріг» підлоги (сумарна висота, підрізка дверей)
14. Порівняння варіантів оздоблення (плитка A чи B, колір стіни) — щоб вирішити вдвох

**Хвиля 4 — інженерка «для себе і для майстрів»:**
15. Автовисоти розеток/вимикачів + підпис висоти на плані
16. Специфікація мереж: к-сть розеток/світла, метраж кабелю за перерізами, довжина труб
17. Зв'язок «вимикач → світильник»; базові перевірки правил
18. Підбір радіатора за тепловтратами кімнати; розкладка теплої підлоги з довжиною контуру
19. Комплект аркушів у один PDF: план + розгортки + розетки + світло + сантехніка + підлоги/стелі

**Хвиля 5 — меблі та 3D:**
20. Зони габариту / проходу + перевірка «влізе / відчиниться» (диван, дверцята шафи, холодильник до кухні)
21. Гардероб-конструктор; кухня — погонні метри й зазори біля техніки
22. Столярні розгортки (шафа / кухня як предмет з розмірами)
23. Збережені ракурси камер у 3D + автоприховування ближніх стін + стеля on/off
24. Реалістичніший 2D-силует меблів; настінні меблі з висотою підвісу
25. Список покупок меблів з цінами; штори/карнизи — заміри

**Хвиля 6 — зручність і надійність:**
26. PWA / офлайн (працювати з планшета під час обміру)
27. Версії проєкту зі снапшотами й відкатом
28. Realtime-редагування вдвох + коментарі-пінки на плані
29. Дефектна відомість (приймання роботи в майстрів) з прив'язкою до місця
30. Дашборд бюджету: план / факт / залишок

## 💤 Що свідомо пропускаємо (комерційне / надлишкове)

Лишаємо в списку як ідеї, але для нашого випадку сенсу мало:

- **Клієнтські процеси** (розд. 28): підписання по кімнатах, ролі, режим «тільки коментування» —
  ми обидва повноправні. *Виняток:* «порівняння варіантів оздоблення» лишаємо — реально корисно вдвох.
- **Нерухомість і маркетинг** (розд. 29): брендований ріелторський план, staging для оголошення,
  бейджі — хіба колись продаватимемо квартиру.
- **Робоча документація для замовника** (розд. 23) у повному обсязі: реєстр креслень, revisions,
  штампи з підписами. *Беремо тільки:* прості плани по розділах + матрицю оздоблення + паспорт
  кімнати — щоб роздрукувати й дати бригаді.
- **Керування проєктом як підрядник** (розд. 27): Gantt, календар постачань за етапами, журнал
  робіт, контакти підрядників. *Беремо тільки:* чеклист етапів, список покупок, дашборд бюджету,
  дефектну відомість.
- **BIM / інтеграції** (розд. 17): IFC, Revit, SketchUp, DWG-обмін, Google Sheets, Telegram-бот,
  публічні тури. Максимум — імпорт `.svg`/`.dxf`, якщо дизайнер дасть файл.
- **Норми та валідація** (розд. 25): клас енергоефективності, ДБН-перевірки, безбар'єрність для
  візка, шляхи евакуації. Цікаво, але не впливає на рішення. *Беремо дрібне:* коеф. заскління,
  зони можливого конденсату, димовий/чадний датчик як символ.
- **Локалізація EN, доступність (screen reader), аудіо-huddle, follow-mode, курсори учасників** —
  для двох людей за одним столом зайве.
- **AI-функції** (розд. 30): редагування природною мовою, генерація плану з фото, чат-асистент —
  **не робимо взагалі** (домовлено). Алгоритмічні помічники (авто-розміри, перевірки помилок) — це
  не AI, їх лишаємо.

> Технічне (E2E-тести, Sentry, ліміт 1 МБ Firestore) — це не фічі продукту, а гігієна коду;
> тримати в issues, не тут.
