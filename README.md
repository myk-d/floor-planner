# Планувальник квартири

Приватний 2D-редактор планування квартири з розстановкою меблів та експортом
креслень на синьому тлі («blueprint»). Доступ лише для двох людей через Firebase
(Google-авторизація).

Стек: Vite + React 19 + TypeScript + Tailwind CSS v4 + Zustand + React Router v7 +
Konva (react-konva) + Firebase (Auth + Firestore + Hosting).

## Команди

```bash
npm run dev       # dev-сервер (http://localhost:5173)
npm run build     # tsc -b && vite build
npm run lint      # eslint
npm run test      # vitest (юніт-тести домену)
npm run deploy    # build + firebase deploy
```

`http://localhost:5173/preview.html` — окрема dev-сторінка з демо-сценою для
роботи над рендером канви й експортом без Firebase.

## Перше налаштування Firebase

1. Створи новий проєкт у [Firebase Console](https://console.firebase.google.com/).
2. **Authentication → Sign-in method →** увімкни **Google**.
3. **Authentication → Settings → Authorized domains →** додай `localhost` (та
   свій майбутній домен хостингу).
4. **Firestore Database →** створи базу (production mode).
5. **Project settings → General → Your apps →** додай Web-застосунок і скопіюй
   значення `firebaseConfig` у файл `.env` (взірець — `.env.example`).
6. Впиши другий дозволений email:
   - `src/constants/allowlist.ts` → `ALLOWED_EMAILS`
   - `firestore.rules` → функція `allowedEmails()`
7. `.firebaserc` → заміни `REPLACE_ME` на ID проєкту.
8. `npx firebase deploy --only firestore:rules`

Після цього `npm run dev`, вхід через Google — і можна працювати.

## Що вміє редактор

- Стіни: малювання ланцюгом, товщина (пресети 5–20 см), матеріал (блоки/цегла/бетон/
  гіпсокартон/дерево/скло), перетягування вузлів, розбити/видалити через контекст-меню,
  прив'язка до сітки/вузлів/кутів.
- Кімнати: прямокутні, полігональні, **авто-визначення з контурів стін**; назва, площа,
  периметр, покриття підлоги (паркет/ламінат/плитка/килим/бетон — колір + штриховка).
- Двері / вікна / прохід на стінах.
- Каталог меблів (~100 позицій, 11 категорій) з drag&drop у точку; переміщення, поворот,
  ресайз, колір, підпис; множинний вибір рамкою/Shift, вирівнювання, копіювання (Ctrl+C/V),
  зсув стрілками.
- Поверхні (Draw Surface): кольорові зони підлоги без стін (килим, зона плитки); трансформер
  меблів на полотні (обертання/ресайз ручками); шаблони кімнат L / П / Т.
- Інженерні шари: розетки/вимикачі/світло/щитки, виводи води й каналізації, стояки,
  радіатори, термостати; лінії розведення кабелів і труб (із перерізом); групи/лінії з
  легендою та кольором за групою.
- Ремонт: зони стяжки / штукатурки / утеплення / гідроізоляції / теплої підлоги; режим
  «до/після ремонту» (червоні — знести, зелені — нові).
- Розгортки стін: вертикальна проєкція стіни з вікнами/дверима, меблями й розмірами (PNG/PDF).
- Розміри: авто по стінах, скумулятивні ланцюги по периметру, ручні лінії, «виміряти», компас.
- 3 режими відображення (лінійний / синє креслення / кольоровий) + процедурні текстури
  матеріалів і покриттів.
- **3D-вигляд** (перемикач 2D/3D): екструдовані стіни з отворами, підлоги з текстурами,
  меблі-об'єми, орбітальна камера.
- Шари з видимістю та блокуванням, зум/пан/«за розміром», undo/redo, автозбереження у Firestore.
- Експорт: синє креслення / лінійний / кольоровий, **PNG / PDF / SVG**, аркуш A4–A1 з
  орієнтацією, масштаб 1:20–1:200 або «вписати», штамп, специфікація меблів, експлікація
  приміщень. Імпорт/експорт `.floorplan` (JSON-файл проєкту).
